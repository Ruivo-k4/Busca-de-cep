Como usar o Busca Cep?
O uso é bem simples e prático, mas existem algumas regrinhas importantes. Como os dados vêm de uma base externa (por meio de uma API), precisamos respeitar alguns limites para garantir o resultado correto.
Caso use CEP
Se for perquisar utilizando o CEP, é nescessario:
  • Utilizar 8 digitos numéricos.
  • Não utilizar espaços entre os números.
  • Ser um cep brasileiro.
Caso use Localidade
Se for utilizar a localidade, é necessário:
  • Obrigatóriamente os três campos estarem preenchidos.
  • As informações serem coerentes entre sí (Logradouro existir em cidade, ela existir no UF)
  • As informações digitadas serem brasileiras
